# 任务：统一API响应数据结构

状态: 已完成
创建时间: 2025-08-21 16:08:59

## 目标
统一所有API接口的响应数据结构，采用标准格式：
```json
{
  "code": "状态码",
  "data": "实际数据内容",
  "msg": "响应信息"
}
```

## 当前问题分析
- 现有接口直接返回业务数据，缺乏统一的响应格式
- 没有标准的错误处理和状态码规范
- 前端需要统一的数据结构来处理响应

### 统一响应格式
所有API接口现在都返回以下格式：
```json
{
  "code": "200",
  "data": {...},
  "msg": "操作成功"
}
```

### 状态码规范
- 200: 成功
- 201: 创建成功
- 400: 请求错误
- 401: 未授权
- 403: 禁止访问
- 404: 资源不存在
- 409: 冲突
- 422: 数据验证失败
- 500: 服务器内部错误
- 503: 服务不可用
