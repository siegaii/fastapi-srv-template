# 任务：添加超级用户初始化和用户注册接口

状态: 已完成
目标: 1. 在user表中默认内置一个超级用户；2. 创建一个用户注册接口，支持用户名和密码创建用户

## 需求分析

### 1. 超级用户初始化
- 在数据库初始化时自动创建一个默认的超级用户
- 用户名: admin
- 密码: admin123 (需要哈希加密)
- 邮箱: admin@example.com
- 设置 is_superuser=True, is_active=True

### 2. 用户注册接口
- 创建 POST /api/v1/user/register 接口
- 接收用户名、密码、邮箱参数
- 验证用户名和邮箱唯一性
- 密码哈希加密后存储
- 返回创建成功的用户信息

## 技术实现方案

### 数据库初始化改进
- 修改 `app/core/database.py` 的 `init_db()` 函数
- 添加超级用户创建逻辑
- 使用 user_service 的密码哈希功能

### API接口开发
- 在 `app/schemas/user.py` 中添加 `UserRegisterRequest` 模型
- 在 `app/services/user_service.py` 中添加 `register_user` 方法
- 在 `app/api/v1/user.py` 中添加注册路由
